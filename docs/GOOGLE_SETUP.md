# 구글 로그인 동기화 준비하기 (한 번만 하면 됩니다)

PC와 노트북의 설정을 같게 쓰려면, 앱이 사용자의 구글 계정으로 로그인해서 **앱 전용 숨김 저장 공간**(구글 드라이브의 `appDataFolder`)에 설정을 올려야 합니다.
이 로그인 권한은 **사용자의 구글 클라우드 계정에서만 만들 수 있어서**, 아래 단계는 사용자가 직접 해야 합니다. (약 20~30분, 무료)

> 이 앱은 구글 드라이브의 **다른 파일에는 접근하지 않습니다.** 요청하는 권한은 `drive.appdata` 하나뿐입니다.
> (구글 로그인 화면에 "이 앱의 구성 데이터를 Google 드라이브에서 보고 관리" 라고만 표시되면 정상입니다.)

## 1단계. 구글 클라우드 프로젝트 만들기
1. 인터넷 브라우저에서 https://console.cloud.google.com 에 접속하고, 동기화에 쓸 구글 계정으로 로그인합니다.
2. 화면 맨 위의 프로젝트 이름(또는 "프로젝트 선택")을 누르고 **새 프로젝트**를 누릅니다.
3. 프로젝트 이름에 `SON AI Office` 를 적고 **만들기**를 누릅니다. 잠시 기다린 뒤 만들어진 프로젝트가 선택되어 있는지 확인합니다.

## 2단계. Google Drive API 켜기
1. 왼쪽 메뉴(☰) → **API 및 서비스** → **라이브러리**를 엽니다.
2. 검색창에 `Google Drive API` 를 입력하고 결과를 눌러 **사용**을 누릅니다.

## 3단계. 동의 화면 설정하기
1. 왼쪽 메뉴 → **API 및 서비스** → **OAuth 동의 화면**을 엽니다. (새 화면에서는 **Google Auth Platform** → **브랜딩/대상**으로 보일 수 있습니다.)
2. 앱 이름: `SON AI Office`, 사용자 지원 이메일: 사용자의 이메일을 고릅니다.
3. 대상(사용자 유형)은 **외부**를 고릅니다.
4. 연락처 이메일에 사용자의 이메일을 적고 저장합니다.
5. **게시 상태가 "테스트"** 이면 **테스트 사용자**에 사용자 본인의 구글 이메일을 추가합니다. (PC와 노트북에서 같은 계정을 쓰면 한 번만 추가하면 됩니다.)
   - 참고: "테스트" 상태에서는 구글이 로그인 유지 기간을 **7일**로 제한할 수 있습니다. 7일마다 다시 로그인하라고 나오면 정상입니다. 혼자 쓰는 앱이라면 "프로덕션으로 게시"를 누르지 않고 그대로 두셔도 됩니다.

## 4단계. 접근 권한(범위) 추가하기
1. **데이터 액세스**(또는 "범위") 메뉴에서 **범위 추가 또는 삭제**를 누릅니다.
2. 목록에서 `.../auth/drive.appdata` ("Google 드라이브에서 앱 전용 구성 데이터 보기/관리") **하나만** 체크하고 저장합니다.
   - 다른 드라이브 권한(`drive`, `drive.file` 등)은 **체크하지 마세요.**

## 5단계. 로그인용 ID 만들기 (가장 중요)
1. 왼쪽 메뉴 → **API 및 서비스** → **사용자 인증 정보**를 엽니다.
2. **+ 사용자 인증 정보 만들기** → **OAuth 클라이언트 ID**를 누릅니다.
3. 애플리케이션 유형은 반드시 **데스크톱 앱**을 고릅니다. 이름은 `SON AI Office PC` 처럼 적습니다.
4. **만들기**를 누르면 **클라이언트 ID**와 **클라이언트 보안 비밀번호** 두 개가 나옵니다. 둘 다 복사해 둡니다.
   - 이 두 값은 앱의 **설정 → 동기화** 화면에 붙여 넣습니다. (코드나 저장소에는 넣지 않습니다.)
   - 클라이언트 보안 비밀번호는 다른 사람에게 보여 주지 마세요.

## 6단계. 앱에서 연결하기
1. 앱 → **설정 → 동기화**를 엽니다.
2. 5단계에서 복사한 클라이언트 ID와 보안 비밀번호를 붙여 넣고 **저장**을 누릅니다.
3. **구글로 로그인**을 누르면 브라우저가 열립니다. 로그인하고 권한을 허용한 뒤 앱으로 돌아옵니다.
4. 상태 줄에 "마지막 동기화 시각"이 보이면 성공입니다.
5. **노트북에서도** 같은 클라이언트 ID/비밀번호를 넣고 같은 구글 계정으로 로그인하세요.

## 문제가 생기면
| 증상 | 확인할 것 |
|---|---|
| "액세스 차단됨: 앱이 확인되지 않음" | 3단계의 **테스트 사용자**에 지금 로그인하는 이메일을 추가했는지 확인 |
| "redirect_uri_mismatch" | 5단계에서 유형을 **데스크톱 앱**으로 만들었는지 확인(웹 애플리케이션이면 안 됨) |
| "Access Not Configured / API not enabled" | 2단계 Google Drive API를 **사용** 상태로 켰는지 확인 |
| 며칠 뒤 다시 로그인하라고 나옴 | 3단계 참고: 테스트 상태의 7일 제한입니다. 다시 로그인하면 됩니다. |

## 동기화되는 것 / 안 되는 것
- **동기화됨:** 앱 설정, 부서와 AI 배정, 마이클 운영 규칙, 스킬, 자동 실행 조건, 한국어 문구 설정, 기억(메모리) 파일
- **동기화 안 됨:** 각 AI의 로그인 정보(기기마다 따로 로그인), 실행 중인 작업과 터미널 기록, **API 키(기본값)**
- API 키는 사용자가 직접 켠 옵션과 사용자가 정한 비밀번호가 있을 때만 암호화해서 올립니다.
- 두 기기에서 같은 설정을 동시에 고치면 덮어쓰지 않고 "PC 버전 / 노트북 버전" 중에서 고르게 보여 줍니다.
