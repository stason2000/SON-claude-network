# 회사 로고 사용 안내

에이전트 선택 화면과 카드에는 어떤 AI가 실행 중인지 알려 주기 위해 각 회사의 로고를 표시합니다.

- 로고 데이터 출처: [Simple Icons](https://simpleicons.org) (CC0 1.0). 로고 자체의 상표권은 각 회사에 있습니다.
- 사용 목적: 해당 AI 서비스를 식별하는 용도뿐이며, 회사와의 제휴나 보증을 뜻하지 않습니다.
- 로고가 있는 것: Claude, Gemini, Qwen, Cursor, GitHub Copilot, OpenCode, Kimi.
- 로고가 없는 것(직접 그린 그림 유지): Codex(OpenAI), Grok, Antigravity, Crush, Pi, 기타.
- 되돌리는 법: `src/renderer/src/scene/office/brandLogos.ts`에서 항목을 지우면 도트 그림으로 돌아갑니다.
